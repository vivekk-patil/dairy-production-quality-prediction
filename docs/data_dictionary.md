# Data Dictionary (SYNTHETIC DATA)

> All data was generated by `src/01_generate_data.py` (seed=42). It is synthetic and must not be presented as real factory data.

## production.csv

| Column | Type | Description |
|---|---|---|
| `event_id` | str | Globally unique event key (join key across all files) |
| `batch_number` | str | Plant batch counter; RESET several times -> NOT unique. Identifier only |
| `batch_id` | str | 'B'+batch_number; reused after resets -> NOT unique. Never join on it alone |
| `production_timestamp` | str | Batch completion time = prediction time |
| `production_line` | str | L1 / L2 / L3 |
| `shift` | str | morning 06-14, evening 14-22, night 22-06 (by completion hour) |
| `production_volume_l` | str | Litres of finished product |
| `production_duration_min` | str | Run time incl. downtime (minutes) |
| `machine_speed` | str | Line speed setting (rpm) |
| `ambient_temperature` | str | Plant ambient temperature (deg C) |

## raw_material.csv

| Column | Type | Description |
|---|---|---|
| `event_id` | str | Join key |
| `batch_id` | str | Non-unique batch label (redundant with production) |
| `supplier_id` | str | S01-S10 (+S11 onboarded late in the timeline) |
| `raw_material_volume` | str | Litres of raw milk consumed |
| `raw_material_age` | str | Hours between collection and processing |
| `fat_percentage` | str | Fat content (%) |
| `protein_percentage` | str | Protein content (%) |
| `acidity` | str | Titratable acidity (% lactic acid) |
| `raw_material_quality_score` | str | Composite incoming-quality score 0-100 |

## machine.csv

| Column | Type | Description |
|---|---|---|
| `event_id` | str | Join key |
| `batch_id` | str | Non-unique batch label |
| `machine_temperature` | str | Pasteurisation temperature (deg C); setpoint 72 |
| `pressure` | str | Line pressure (bar) |
| `downtime` | str | Unplanned stoppage minutes during the batch |
| `maintenance_age_days` | str | Days since last maintenance of the line |
| `vibration` | str | Vibration (mm/s); sensor missing more often on L3 |

## quality.csv

| Column | Type | Description |
|---|---|---|
| `event_id` | str | Join key |
| `batch_id` | str | Non-unique batch label |
| `quality_test_timestamp` | str | Lab result time (~24h after production) - determines WHEN the label becomes known |
| `moisture_percentage` | str | Lab moisture (%); LATER than prediction time -> not a valid predictor; missing mostly at night |
| `quality_status` | str | ACCEPTED / REJECTED (lab verdict) |
| `rejected` | str | TARGET: 1 = rejected, 0 = accepted |

## Known injected data-quality issues (for the cleaning step to discover)

- Batch numbers reset 4 times (batch_id duplicates); event_id is the only safe key.
- Exact duplicate rows in production / machine / quality.
- Sentinel / impossible values (-999 ambient, negative volumes, 0 deg C temperature, protein x10, ...).
- Events missing from raw_material / machine / quality files.
- Quality timestamps earlier than production; label conflicts between `quality_status` and `rejected`.
- Moisture missing ~4-6% in morning/evening vs ~30%+ at night; vibration missing more on L3.
- Supplier S11 appears only near the end of the timeline; S07 degrades in the second half (drift).
