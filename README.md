# Dairy Production Batch Quality Rejection Prediction (Sections 1-9)

> **ALL DATA IN THIS PROJECT IS SYNTHETIC.** It was generated by `src/01_generate_data.py` (seed 42) for a fictional
> Chennai dairy plant. It must not be presented as real factory data; every pattern is invented.

## Run order
```
pip install pandas numpy scikit-learn matplotlib seaborn tabulate joblib
cd src
python 01_generate_data.py        # 4 CSVs (~300k events) + docs/data_dictionary.*
python 02_data_quality.py         # cleaning/merge audit  -> reports/data_quality_report.md
python 02b_build_features.py     # leakage-safe feature table -> data/processed/features_all.pkl
python 03_eda.py                  # 13 figures + reports/eda_report.md
python 04_leakage_audit.py        # reports/leakage_audit.md (brute-force check + leak demo)
python 05_split_and_preprocess.py # reports/split_and_preprocessing.md, docs/feature_dictionary.md, models/preprocessor.joblib
```

## Layout
| Path | Content |
|---|---|
| `src/cleaning.py` | dedup, event_id joins (`validate='1:1'`), invalid -> NaN, label-availability time |
| `src/features.py` | 30+ engineered features; delay-aware label-history logic |
| `src/splitting.py` | chronological 70/15/15 split with label-delay embargo |
| `src/preprocessing.py` | ColumnTransformer: scale+median impute+indicators, OHE, frequency encoder |
| `reports/` | data quality, EDA (figures + interpretations), leakage audit, split & preprocessing |
| `docs/` | data dictionary, feature dictionary |

## Key design decisions
* **Join key:** `event_id`. `batch_id` is reused after 4 resets; joining on it would inflate 300k rows to ~1.2M.
* **Prediction time** = batch completion. Moisture and status are next-day lab results -> excluded.
* **Label history** (supplier / shift / line / previous batch) only uses labels with `label_avail_ts <= t`.
* **Embargo** around split boundaries; `TimeSeriesSplit` with a gap larger than the reporting delay.
* **Honest baseline signal** (from the leakage demo, validation): ROC-AUC 0.805 / PR-AUC 0.34 with a plain gradient-boosting model;
  adding the moisture leak would show 0.935 / 0.75.
